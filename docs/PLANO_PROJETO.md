
# Meu Scanner

## Objetivo
Criar uma PWA para identificação, cadastro e consulta compartilhada de produtos de supermercado.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- PWA
- Supabase
- Google Gemini
- GitHub Pages

## Funcionalidades planejadas
1. Scanner de produtos por câmera.
2. Reconhecimento de produtos por IA.
3. Cadastro de produtos.
4. Armazenamento de fotografias.
5. Catálogo compartilhado.
6. Pesquisa de produtos.
7. Leitura de código de barras.
8. Histórico de escaneamentos.

## Regras
- Não expor chaves secretas no frontend.
- Evitar produtos duplicados.
- Permitir correção dos dados identificados pela IA.
- Proteger o banco de dados.
- Testar cada etapa antes de avançar.

## Estado atual
